# Capstone Project
Personal Media Tracker
This program will keep a list of shows and books finished. Add entry, view entries, search, delete, save & quit. 
Each entry will store: title, type of content (book/show/movie), a rating and notes.
With loops and libraries it makes the program more interactive and engaging with the user
Used ChatGBT for program coding
Added media stats dashboard
Analysis includes total number of entries, average ratings and breakdown of media types
